# creator types 发布说明

## 准备工作

新建远端名称为 cocos

## 发布步骤

在编辑器主仓库根目录下执行

```bash
npm run build:dts
```

1. 先更新生成 dts 文件
2. 修改版本号
3. 检查本地的定义修改，修改版本号，提交到 github master 分支，并推送到远程仓库。
4. 在当前仓库下，运行 'npm publish' 命令，将代码发布到 npmjs.com ，这个命令有两个前后钩子
   - 前置钩子：会检查当前发布的版本号是否已经推送到远程分支，不一致需要先上传
   - 后置钩子：会自动打 tag 到 cocos 远端上
